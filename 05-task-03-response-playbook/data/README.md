# Task 3 — Operational Data Registers

This directory contains the authoritative structured datasets
supporting the Task 3 response playbook.

## 1. Response Actions Register

**[Open response-actions.csv](response-actions.csv)**

This dataset records the planned sequence of incident response
activities, including the initial response period and the
subsequent stages of containment, investigation, eradication,
recovery and closure.

The register should be interpreted alongside the main playbook.

## 2. Evidence Register

**[Open evidence-register.csv](evidence-register.csv)**

This register documents planned forensic evidence preservation
and handling.

Its purpose is to support traceability, integrity verification,
secure storage and chain-of-custody arrangements.

Evidence marked as planned or not collected must not be
interpreted as having been acquired.

## Data governance

These files are the **canonical Task 3 records**.

Original header-only templates are retained separately under
[deprecated-templates/](../deprecated-templates/).

Do not substitute deprecated templates for these records.
