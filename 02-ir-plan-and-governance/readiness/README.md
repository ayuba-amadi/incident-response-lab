# Task 2 — Incident Response Preparation and Readiness

## Purpose

This directory contains proposed measures for improving
Northbridge Skills Institute's ability to respond to
cybersecurity incidents and restore essential services.

These are recommendations for a fictional institute.
They must not be mistaken for controls already deployed
or independently verified as operational.

## Readiness improvement document

**[Read Preparation Improvements](preparation-improvements.md)**

The document addresses four preparedness areas.

### 1. Backup Isolation and Recoverability

Improve confidence in backup resilience, separation,
test restoration and suitability for controlled recovery.

A completed backup job is not equivalent to verified
restorability or freedom from compromise.

### 2. Independent Contacts and Secure Communications

Maintain access to approved contact and escalation
information when file services, identity systems
or normal communication channels are disrupted.

The scenario's inaccessible contact information
illustrates the need for independently maintained
communications arrangements.

### 3. Monitoring and Detection Coverage

Strengthen endpoint and server monitoring, alert
handling and investigation visibility.

Proposed improvements should not be described as
already implemented across all Northbridge systems.

### 4. Training and Exercise Readiness

Improve role familiarity, escalation practice and
the ability to test response arrangements through
planned exercises and measurable follow-up.

## Implementation framework

The proposed improvements are accompanied by
responsible ownership, required resources,
prioritisation and readiness checks in the
authoritative improvement document.

An assigned owner or target is not proof that
implementation has occurred.
