# Task 3 — Deprecated CSV Templates

## Overview

This directory preserves historical CSV scaffolds
from the original repository structure.

These files are retained for provenance and are
not the authoritative Task 3 response records.

## Template 1 — Original Evidence Register

**[Open historical evidence-register.csv](evidence-register.csv)**

This file is a preserved scaffold rather than

**[Canonical Evidence Register](../data/evidence-register.csv)**

## Template 2 — Original Playbook Register

**[Open historical playbook.csv](playbook.csv)**

This file was an initial scaffold for recording
playbook activities.

The current authoritative action register is:

**[Canonical Response Actions Register](../data/response-actions.csv)**

## Why preserve superseded templates?

The original template files provide evidence of
the project's initial documentation structure.

Retaining them distinguishes original scaffolds
from the completed planning records.

Their presence should not be interpreted as
an indication that the assessment is unfinished.

## Rules for use

- Do not use historical templates in place of canonical records.
- Do not present their contents as completed response activities.
- Do not merge template rows into completed registers.
- Use the main playbook when interpreting actions and evidence plans.
