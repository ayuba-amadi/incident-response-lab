# Visual production guidance

All visual material must be **editable from its source** (Mermaid `.mmd`, tables `.csv`, or native Word elements). Diagrams can be exported as SVG/PNG for embedding only after checking labels against the case. Use captions, figure numbers, and alt-text descriptions in the Word report. Avoid decorative illustrations that cannot be linked to an assessment requirement. Nothing here represents observed telemetry or a real-world forensic examination.
