# Task 1 — Deprecated Templates

## Purpose

This directory preserves two original scaffold CSV files
for repository provenance.

They are **not the current assessment registers** and
must not be used as completed Task 1 evidence outputs.

## Preserved files

### timeline.csv

[Open the historical timeline template](timeline.csv)

This is a historical scaffold retained for reference.
For the completed chronological analysis, use the
[Incident Chronology](../analysis/incident-chronology.md)
and the [Incident Timeline visual](../visuals/incident-timeline.svg).

### investigation-priorities.csv

[Open the historical investigation-priorities template](investigation-priorities.csv)

This is a superseded scaffold.

The authoritative completed register is:

[Canonical Investigation Priorities](../data/investigation-priorities.csv)

## Why these files are retained

Keeping historical scaffolds makes it possible to distinguish
initial project templates from completed analytical deliverables.

Their presence does not imply that the current task is incomplete.

## Usage warning

Do not import these templates into the final assessment in
place of the completed records under `../data/`.

Do not infer that a template contains incident findings.
