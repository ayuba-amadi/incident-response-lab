## Rendering guidance

The rendered figures can be used in GitHub documentation
and academic report preparation.

SVG files are useful where scalable graphics are required.
PNG files provide straightforward image previews.

When modifying diagram content, update the editable source
and inspect any regenerated exports before publishing them.

## Preservation policy

This documentation change does not alter existing images,
perform a new render or modify the incident analysis.
