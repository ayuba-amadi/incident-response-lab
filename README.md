# Incident Response Planning and Ransomware Response Simulation

## ICDFA GRC105 — Academic Assessment Portfolio

This repository contains six completed assessment tasks based on a fictional ransomware incident at Northbridge Skills Institute.

## Assessment scenario

Northbridge Skills Institute is fictional. The initial assessment identifies a provisional High severity position at 08:45 WAT on Day 0.

Planned response activities and simulated decisions are not evidence of completed real-world actions.

## Supporting documentation

Each task contains its supporting analysis, registers and explanatory README files. Relevant directories also include Mermaid diagrams and rendered images.
