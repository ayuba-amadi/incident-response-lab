# Deprecated Task 5 dataset variants

The canonical tabletop records are maintained under [`../data/`](../data/):

- [`exercise-decision-log.csv`](../data/exercise-decision-log.csv)
- [`corrective-actions.csv`](../data/corrective-actions.csv)

The preserved files in this directory are earlier root-level variants. They contain the same six exercise positions and six corrective-action IDs as the canonical records, but differ in wording, role labels, rationale detail and status phrasing. They are retained for provenance only and must not be merged with or treated as additional current records.
